하네스 조립도

Claude Code 에서 모델이 받는 지시와 설정은 두 가지에 따라 달라진다. 하나는 어느 폴더에서 시작했는지이고, 다른 하나는 새 에이전트를 어떤 방식으로 띄웠는지이다. 새로 띄운 에이전트는 디스크에 저장된 파일을 다시 읽는다. 메인 대화에서만 오간 내용은 새 에이전트에 전달되지 않는다.

조립도

시작 폴더와 띄우는 방식을 바꾸면, 오른쪽 새 세션의 각 항목을 어디에서 받는지가 바뀐다. 항목을 누르면 아래에 출처와 근거가 나온다.

띄우는 방식

조립도는 옆으로 밀어서 볼 수 있다.

규칙이 겹치는 다섯 방식

흔히 "규칙의 우선순위"라고 부르지만, 설정의 종류마다 겹치는 방식이 다르다. 이 절은 다섯 가지 방식을 각각 다른 모양으로 보여 준다. 숫자는 위에서 고른 시작 폴더를 기준으로 한다.

문서만 읽어서는 알기 어려운 점

아래 내용은 공식 문서의 한 문장만으로는 알기 어렵다. 여러 규칙을 함께 적용하거나 실제로 실행해 봐야 알 수 있다.

근거를 고친 기록

이 화면의 근거표에는 한때 잘못된 내용이 있었다. 공식 문서를 요약하는 과정에서 생긴 오류였다. 실행 결과를 관찰하고 원문을 다시 대조해서 바로잡았다.

질문으로 찾기

질문을 누르면 화면이 그 답을 확인할 수 있는 상태로 바뀐다.

다른 하네스 데이터로 다시 그리기

추출 스크립트는 설정 파일을 읽기만 한다. 비밀값은 저장하지 않고, 설정 키의 이름과 파일의 줄 수, 실행 파일의 이름만 남긴다.

1. 추출

하네스 지도 폴더에 있는 harness-map.py 를 실행한다. Claude Code 를 쓰는 사용자 계정으로 실행해야 같은 파일을 읽을 수 있다. --cwd 는 비교할 시작 폴더마다 한 번씩 적는다.

python3 harness-map.py --cwd ~/프로젝트A --cwd ~/프로젝트B -o harness.json
